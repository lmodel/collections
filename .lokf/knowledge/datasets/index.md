# Datasets

* [collections LinkML schema](collections-linkml-schema.md) - The LinkML schema of the Collections Ontology (CO) 2.0, `src/collections/schema/collections.yaml` (schema id `https://w3id.org/lmodel/collections`, version 2.0): seven classes, six with CO's name and IRI and `CoElement` its own, sixteen slots, and mappings from CO's alignment file. Its `lokf adapt` copy `.lokf/collections.yaml`, rooted on `Collection` and `CoElement`, is the bundle's domain schema.
* [Copy of CO's OWL file](collections-ontology-copy.md) - `src/collections/schema/upstream/collections.owl`, the Collections Ontology 2.0's OWL file copied unchanged from commit `619e7b0` of its GitHub repository and matched by its git object hash, which the tests hold the schema to.
* [Generated artefacts](generated-artefacts.md) - What `just gen-project` and `just gen-doc` generate from the schema: the twelve formats in `project/`, the Python dataclasses and Pydantic models in `src/collections_linkml/datamodel/`, the merged schema in `docs/schema/` and the element pages in `docs/elements/`.
* [Tests and example data](test-data.md) - The tests under `tests/`: 13 valid examples, 12 counter-examples the validator rejects and 14 that break a rule only a test checks, the checks against CO's OWL and alignment files and the watch's stubbed answers, and the 13 released neighbour copies the adapt copy is held apart from.
* [Copy of CO's alignment file](collections-alignment-copy.md) - `src/collections/schema/upstream/alignment.owl`, CO's alignment with SWAN Collections 1.2, the ontologydesignpatterns.org patterns, the Music Ontology and OAI-ORE, copied unchanged from commit `619e7b0` and matched by its git object hash; the schema's exact, narrow and broad mappings follow it.
