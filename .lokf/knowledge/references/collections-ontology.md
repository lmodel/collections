# The Collections Ontology (CO) 2.0

The Collections Ontology (CO) describes sets, bags and lists in OWL 2 DL. Its authors are Paolo Ciccarese and Silvio Peroni. Its GitHub repository, `collections-ontology/collections-ontology`, is an export of the project's Google Code site, and its master branch last changed on 2019-09-09, at commit `619e7b0`.[^collections-ontology] The paper is "The Collections Ontology: creating and handling collections in OWL 2 DL frameworks", Semantic Web 5(6), 2014, pages 515 to 529.[^sw-130121]

The repository states no licence. The Google Code archive's record of the project gives `asf20`, the Apache License 2.0, for its code and `cc3-by`, Creative Commons Attribution 3.0, for its content.[^project.json] NOTICE says that the repository copies CO's OWL file and its alignment file under those terms, and gives the credit.[^notice]

CO's namespace is `http://purl.org/co/`. NOTICE and the schema cite the file on GitHub, because the PURL now ends at a SourceForge page that answers 404.
