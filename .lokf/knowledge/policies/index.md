* [Licence and attribution](license-and-attribution.md) - The licences: Apache-2.0 for the schema and code, CC BY 4.0 for the knowledge bundle, Apache-2.0 for code and CC BY 3.0 for content for the copied CO file, as CO's Google Code archive gives them, and MIT for the copier template's scaffolding.
* [Security policy](security-policy.md) - How to report a vulnerability (GitHub's private vulnerability reporting), which release receives fixes (the latest), what executes in the repository and what holds each surface, the ruleset on `main`, and the two repository settings that are not yet in force.
* [AI covenant](ai-covenant.md) - The rules for AI-assisted work in this repository: the contributor owns what they submit, every element renders a class or property of CO 2.0 cited by its axiom, CO's IRIs are kept, the copied OWL file stays CO's, and the scheduled librarian's changes go through a reviewed pull request.
